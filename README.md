# Gemma 4 E4B روی Daytona + ربات تلگرام

مدل **Gemma 4 E4B بدون سانسور** (نسخه HauhauCS، ‏Q4) روی یک سندباکس Daytona بالا می‌آید
(با llama.cpp) و از طریق یک ربات تلگرام قابل استفاده است.
سندباکس: ۴ هسته CPU، ‏۸ گیگ رم، ۱۰ گیگ دیسک (Daytona Tier 1).

## قدم صفر — ساخت سندباکس در سایت Daytona

یک Sandbox جدید بساز و این دو تنظیم را حتماً درست کن:

- **Ephemeral: خاموش (تیک نخورده باشد)** — وگرنه با توقف سندباکس همه‌چیز پاک می‌شود.
- **Auto-stop: ‏0** — وگرنه سندباکس بعد از ۱۵ دقیقه بی‌کاری خاموش می‌شود و ربات می‌میرد.

## قدم ۱ — گرفتن کدها (یک دستور)

</div>

```bash
git clone https://github.com/Iman0936/daytona-gemma4-telegram.git
cd daytona-gemma4-telegram
```


## قدم ۲ — بالا آوردن همه‌چیز (فقط یک دستور)

</div>

```bash
bash start.sh
```

<div dir="rtl">

همین. دفعه‌ی اول، جلوی خودت این کارها را می‌کند: نصب را انجام می‌دهد
(باینری آماده llama.cpp از GitHub — اگر نشد از سورس بیلد می‌کند — دانلود مدل
از Hugging Face، حدود ۵٫۸ گیگ، و نصب کتابخانه پایتون ربات)، بعد توکن ربات و
آیدی عددی تلگرامت را یک بار می‌پرسد، همان لحظه اعتبار توکن را با خود تلگرام
چک می‌کند و فقط داخل همین سندباکس ذخیره می‌کند (`secrets.env` — هرگز وارد گیت
نمی‌شود). بعد سرور مدل، ربات و نگهبان (watchdog) را بالا می‌آورد و صبر می‌کند
تا سرور واقعاً سالم شود.

دفعات بعد همان یک دستور کافی است: چیزی نمی‌پرسد، فقط مطمئن می‌شود همه‌چیز
بالاست. ترمینال را هم که ببندی همه‌چیز در پس‌زمینه می‌ماند و watchdog اگر
بخشی از کار بیفتد (حتی اگر ربات بی‌صدا هنگ کند) خودش دوباره بالا می‌آوردش.

برای توقف کامل:

</div>

```bash
pkill -f watchdog.sh; pkill -f llama-server; pkill -9 -f "python.*bot.py"
```

## تنظیمات مدل (از داکیومنت رسمی گوگل)

- Sampling رسمی Gemma 4: ‏`temperature=1.0`، ‏`top_p=0.95`، ‏`top_k=64` (داخل `bot.py` ست شده)
- پرچم `--jinja` برای llama.cpp الزامی است تا چت‌تمپلیت درست اعمال شود.
- حالت Thinking **روشن** است (توکن `<|think|>` ابتدای system prompt می‌آید)؛ متن فکر کردن در یک قاب نقل‌قول جمع‌شونده بالای جواب نشان داده می‌شود (حین استریم فقط دمِ فکر در نقل‌قول ساده می‌آید) و فکر در حافظه‌ی گفتگو ذخیره نمی‌شود. برای خاموش کردنش قبل از اجرا `export THINKING=0` بزن. سقف تولید ۳۲۷۶۸ توکن است (فکر + جواب با هم).
- کانتکست سرور **۶۵۵۳۶** است تا گفتگوهای طولانی در حافظه مدل بماند (کانتکست ذاتی مدل ۱۲۸K است ولی روی رم ۸ گیگ جا نمی‌شود؛ برای جا شدن ۶۴K، کش KV به صورت q8_0 ذخیره می‌شود که حجمش را نصف می‌کند، با افت کیفیت ناچیز — کش ۸ بیتی روی هوش مدل اثر محسوسی ندارد).
- حافظه گفتگو: بات **۱۰۰ نوبت آخر** هر چت را نگه می‌دارد (سقف ۱۲۰٬۰۰۰ کاراکتر) و در فایل `history.json` ذخیره می‌کند، پس با ری‌استارت بات یا سرور هم حافظه نمی‌پرد. با `/reset` حافظه پاک می‌شود. (این فایل در .gitignore است و هرگز نباید commit شود.)
- جواب‌های طولانی: وقتی پیام استریمی به سقف ۴۰۹۶ کاراکتر تلگرام برسد، همان‌جا مهر می‌شود و جواب در **پیام بعدی** ادامه پیدا می‌کند — هیچ جوابی لب سقف متوقف نمی‌شود.
- انتظار سرعت: روی ۴ هسته CPU حدود ۵ تا ۸ توکن بر ثانیه؛ با Thinking روشن جواب دیرتر شروع می‌شود (اول فکر می‌کند) و جواب کامل بسته به سختی سؤال ۱ تا ۳ دقیقه طول می‌کشد.

## عوض کردن مدل (رسمی ↔ بدون سانسور)

پیش‌فرض، مدل **بدون سانسور** HauhauCS با کوانت **Q4_K_P** است (~۵٫۸ گیگ؛ انتخاب کیفیِ کارت مدل).
برای Q4_K_M سبک‌تر (۵٫۳۴ گیگ)، روی سندباکس تازه **قبل از اولین** `bash start.sh` این‌طوری نصبش کن
(بعدش همان `bash start.sh` معمولی کافی است):

</div>

```bash
MODEL_URL="https://huggingface.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive/resolve/main/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf" bash setup.sh
```

<div dir="rtl">

(نسخه رسمی سانسورشده گوگل هم هست: `google/gemma-4-E4B-it-qat-q4_0-gguf`، ‏۵٫۱۵ گیگ.)

## محدود بودن ربات به خودت

ربات فقط به آیدی عددی‌ای جواب می‌دهد که دفعه‌ی اولِ `bash start.sh` وارد
می‌کنی؛ آن آیدی در `secrets.env` همین سندباکس می‌ماند و هیچ‌جای دیگری
نمایش داده نمی‌شود. برای عوض کردنش، مقدار `ALLOWED_IDS` را در `secrets.env`
ویرایش کن و دوباره `bash start.sh` را بزن.

## فایل‌ها

- `start.sh` — **همان یک دستور**: نصبِ هرچه نیست + پرسیدن توکن/آیدی (فقط دفعه‌ی اول) + بالا آوردن کل استک
- `setup.sh` — نصب یک‌باره: llama.cpp + مدل + وابستگی‌های پایتون (خودِ start.sh صدایش می‌زند)
- `watchdog.sh` — نگهبان پس‌زمینه: سرور و ربات را زنده نگه می‌دارد و رباتِ هنگ‌کرده‌ی بی‌صدا را هم ری‌استارت می‌کند
- `bot.py` — ربات تلگرام (polling) با جواب **استریمی**: پیام هم‌زمان با تولید توکن‌ها ویرایش می‌شود و زنده تایپ می‌شود
- `requirements.txt` — فقط `python-telegram-bot`
