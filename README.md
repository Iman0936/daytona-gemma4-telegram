# Gemma 4 E4B روی Daytona + ربات تلگرام

مدل **Gemma 4 E4B بدون سانسور** (نسخه HauhauCS، ‏Q4) روی یک سندباکس Daytona بالا می‌آید
(با llama.cpp) و از طریق یک ربات تلگرام قابل استفاده است.
سندباکس: ۴ هسته CPU، ‏۸ گیگ رم، ۱۰ گیگ دیسک (Daytona Tier 1).

## قدم صفر — ساخت سندباکس در سایت Daytona

یک Sandbox جدید بساز و این دو تنظیم را حتماً درست کن:

- **Ephemeral: خاموش (تیک نخورده باشد)** — وگرنه با توقف سندباکس همه‌چیز پاک می‌شود.
- **Auto-stop: ‏0** — وگرنه سندباکس بعد از ۱۵ دقیقه بی‌کاری خاموش می‌شود و ربات می‌میرد.

## قدم ۱ — گرفتن کدها (یک دستور)

```bash
git clone https://github.com/<YOUR-USERNAME>/daytona-gemma4-telegram.git
cd daytona-gemma4-telegram
```

اگر `git` نبود، جایگزین:

```bash
curl -L -o repo.zip https://github.com/<YOUR-USERNAME>/daytona-gemma4-telegram/archive/refs/heads/main.zip
unzip repo.zip && cd daytona-gemma4-telegram-main
```

## قدم ۲ — نصب (یک دستور)

```bash
bash setup.sh
```

این اسکریپت سه کار می‌کند: باینری آماده llama.cpp را از GitHub می‌گیرد
(اگر نشد، از سورس بیلد می‌کند)، فایل مدل را از Hugging Face دانلود می‌کند
(حدود ۵٫۸ گیگ — چند دقیقه طول می‌کشد) و کتابخانه پایتون ربات را نصب می‌کند.

## قدم ۳ — توکن ربات

از BotFather توکن بگیر و بده به ترمینال:

```bash
export BOT_TOKEN="توکن-ربات-تو"
```

## قدم ۴ — اجرا

```bash
bash run.sh
```

سرور مدل بالا می‌آید و بعد ربات با polling وصل می‌شود. تمام.
برای توقف کامل: `Ctrl+C` و بعد `pkill -f llama-server`.

## تنظیمات مدل (از داکیومنت رسمی گوگل)

- Sampling رسمی Gemma 4: ‏`temperature=1.0`، ‏`top_p=0.95`، ‏`top_k=64` (داخل `bot.py` ست شده)
- پرچم `--jinja` برای llama.cpp الزامی است تا چت‌تمپلیت درست اعمال شود.
- حالت Thinking **روشن** است (توکن `<|think|>` ابتدای system prompt می‌آید)؛ متن فکر کردن به کاربر نشان داده نمی‌شود — موقع فکر فقط «🧠 دارم فکر می‌کنم» می‌بینی و بعد جواب نهایی استریم می‌شود. برای خاموش کردنش قبل از اجرا `export THINKING=0` بزن. سقف تولید ۸۱۹۲ توکن است (فکر + جواب با هم).
- کانتکست سرور **۳۲۷۶۸** است تا گفتگوهای طولانی در حافظه مدل بماند (کانتکست ذاتی مدل ۱۲۸K است ولی روی رم ۸ گیگ جا نمی‌شود؛ برای جا شدن ۳۲K، کش KV به صورت q8_0 ذخیره می‌شود که حجمش را نصف می‌کند، با افت کیفیت ناچیز).
- حافظه گفتگو: بات **۴۰ نوبت آخر** هر چت را نگه می‌دارد و در فایل `history.json` ذخیره می‌کند، پس با ری‌استارت بات یا سرور هم حافظه نمی‌پرد. با `/reset` حافظه پاک می‌شود. (این فایل در .gitignore است و هرگز نباید commit شود.)
- جواب‌های طولانی: وقتی پیام استریمی به سقف ۴۰۹۶ کاراکتر تلگرام برسد، همان‌جا مهر می‌شود و جواب در **پیام بعدی** ادامه پیدا می‌کند — هیچ جوابی لب سقف متوقف نمی‌شود.
- انتظار سرعت: روی ۴ هسته CPU حدود ۵ تا ۸ توکن بر ثانیه؛ با Thinking روشن جواب دیرتر شروع می‌شود (اول فکر می‌کند) و جواب کامل بسته به سختی سؤال ۱ تا ۳ دقیقه طول می‌کشد.

## عوض کردن مدل (رسمی ↔ بدون سانسور)

پیش‌فرض، مدل **بدون سانسور** HauhauCS با کوانت **Q4_K_P** است (~۵٫۸ گیگ؛ انتخاب کیفیِ کارت مدل).
برای Q4_K_M سبک‌تر (۵٫۳۴ گیگ) فقط موقع setup این‌طوری اجرا کن:

```bash
MODEL_URL="https://huggingface.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive/resolve/main/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf" bash setup.sh
```

(نسخه رسمی سانسورشده گوگل هم هست: `google/gemma-4-E4B-it-qat-q4_0-gguf`، ‏۵٫۱۵ گیگ.)

## محدود کردن ربات به خودت (اختیاری)

پیش‌فرض ربات برای همه باز است. برای تست شخصی، آیدی عددی تلگرامت را بده تا فقط خودت بتوانی استفاده کنی:

```bash
export ALLOWED_IDS="آیدی-عددی-تو"
bash run.sh
```

## فایل‌ها

- `setup.sh` — نصب یک‌باره: llama.cpp + مدل + وابستگی‌های پایتون
- `run.sh` — اجرای سرور مدل و ربات با هم
- `bot.py` — ربات تلگرام (polling) با جواب **استریمی**: پیام هم‌زمان با تولید توکن‌ها ویرایش می‌شود و زنده تایپ می‌شود
- `requirements.txt` — فقط `python-telegram-bot`
